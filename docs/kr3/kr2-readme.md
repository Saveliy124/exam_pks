# Экзаменационный центр — Spring Boot и JavaFX

Собственный рабочий backend **Spring Boot 3.5.16**, настольный клиент **Java 21 / JavaFX 21**, общая PostgreSQL 16 в Docker. JavaFX выполняет операции через HTTP REST API; пароль БД и JDBC-драйвер клиенту не нужны. Подготовка к КР3 выполнена по уточнению пользователя от 23.10.2026: требование КР2 о прямом JDBC из JavaFX заменено клиент-серверной архитектурой. Предметная область, данные, формы, ограничения, поиск, статистика и Excel сохранены.

## Запуск на Mac

1. Откройте Docker Desktop и дождитесь готовности.
2. Дважды откройте **«Запустить КР2.command»** в корне проекта.
3. Дождитесь окна «Экзаменационный центр».

Или из терминала в папке проекта:

```sh
./scripts/setup.sh
./run.sh
```

`setup.sh` проверяет Docker, создаёт локальные настройки при первом запуске, применяет схему, собирает Maven-модули и запускает **наши** PostgreSQL и backend. Повторная подготовка сохраняет данные. Первое развёртывание требует интернета для Maven и Docker-образов. Для тренировки откройте **«Демонстрация КР2.command»**: отдельные `exam_center_demo` и backend на порту 8082 сохраняют рабочие записи.

## Компоненты

| Компонент | Назначение | Адрес по умолчанию |
| --- | --- | --- |
| `common` | Модели, REST-контракты, чистые правила, фильтры, расчёты, Excel | Общая библиотека |
| `backend` | REST, бизнес-операции, транзакции Spring, пул соединений и SQL | `http://127.0.0.1:8081` |
| `desktop` | JavaFX / FXML / CSS и HTTP-клиент | Окно на Mac |
| PostgreSQL | Рабочая БД `exam_center`, существующий volume сохранён | `127.0.0.1:55433` |
| Демо-backend | Та же серверная логика для `exam_center_demo` | `http://127.0.0.1:8082` |
| Student Hub | Отдельный пример преподавателя | Его сервер 8080, БД 55434 |

Состояние backend: [health](http://127.0.0.1:8081/actuator/health). Данные в JSON: [snapshot](http://127.0.0.1:8081/api/snapshot). Если сервер недоступен, окно показывает ошибку; после восстановления нажмите «Обновить данные».

## Настройки и завершение работы

JDK 21 и Maven 3.9+ нужны на Mac, JavaFX скачивает Maven. Docker запускает PostgreSQL и наш backend. `run.sh` собирает только `common` и `desktop`, затем выполняет JavaFX Maven-плагин из модуля клиента. Корневой `pom.xml` теперь агрегатор: для запуска нельзя использовать `mvn javafx:run` из корня.

Секреты находятся только в локальной `.env`; Compose передаёт их серверу. `config/database.properties` нужен лишь диагностической консоли. Клиент получает `EXAM_API_URL`, JVM-свойство `exam.api.url` или адрес из `config/client.properties`; по умолчанию 8081. Для собственного адреса:

```sh
EXAM_API_URL=http://127.0.0.1:8083 ./run.sh
```

Внутри Docker backend подключается к `postgres:5432`, с Mac к БД можно обращаться по 55433. Нельзя подставлять `localhost:55433` в контейнер вместо имени сервиса. HTTP-порты и порт БД опубликованы только на `127.0.0.1`. В текущей учебной версии нет авторизации и пользовательских ролей; это отдельная возможная задача КР3.

Закрытие окна сохраняет уже выполненные действия и оставляет сервисы работать. `docker compose --profile demo down` останавливает рабочий и демо-серверы и PostgreSQL, сохраняя volume. Не используйте `down -v` для обычной остановки.

## Проверки и сборка

```sh
./scripts/test.sh       # модульные, PostgreSQL, настоящий HTTP Spring API
./scripts/test-ui.sh    # GUI через настоящий HTTP-сервер в тестовом JVM
./scripts/test-docker-ui.sh # полный GUI через Spring в отдельном Docker-контейнере
mvn -B -ntp clean verify -Pintegration
```

Интеграционные скрипты используют только БД с суффиксом `_test`. Не запускайте два таких прогона одновременно. Графические тесты требуют открытого рабочего стола. Исполняемый backend: `backend/target/exam-backend-3.0.0-exec.jar`; запуск отдельно для разработки: `./scripts/backend-local.sh` (порт 8083). Клиентский JAR не содержит JavaFX и зависимостей; пользуйтесь `run.sh`.

Архив без секретов и сборочных каталогов: `python3 scripts/package-source.py`. Результат — `dist/exam-center-spring-source.zip`. Резервная копия БД: `./scripts/backup.sh`; восстановление только в новую БД описано в инструкции пользователя.

## Windows

Выберите JDK 21 в `JAVA_HOME`, установите Maven 3.9+ и Docker Desktop. Из PowerShell в корне:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Фактическая проверка этой версии проведена на macOS Apple Silicon. Windows-скрипты предоставлены, но на Windows не запускались. В IntelliJ IDEA открывайте корневой `pom.xml`, выбирайте JDK 21 и запускайте `ExamCenterApplication` модуля `desktop` после `setup.sh`.
