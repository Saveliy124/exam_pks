# Требования КР2 и переход к Spring Boot

23.10.2026 пользователь поручил создать собственный рабочий backend как подготовку к КР3 и явно разрешил отступить от пунктов КР2, конфликтующих с этим переходом.

| Пункт | Реализация текущей версии |
| --- | --- |
| Предметная область, три сущности, связи и правила КР1 | Сохранены таблицы и данные exam_center |
| Java 21, Maven, JavaFX, FXML, CSS | Три Maven-модуля, существующие экраны |
| Прямой JDBC из собственного JavaFX | Сознательно заменён REST по указанию пользователя |
| Отдельный собственный backend | Spring Boot, бизнес-операции, транзакции, PostgreSQL JDBC на сервере |
| Docker | Наши PostgreSQL и backend; отдельный demo-backend |
| CRUD, связанные карточки, проверки, подтверждения | Сохранены через HTTP API и серверную валидацию |
| Несколько поисковых полей, два фильтра и сортировка | Сохранены в JavaFX по снимку API; API также фильтрует заявки |
| Не менее пяти показателей | Серверный расчёт статистики с периодом |
| Excel через FileChooser | Сохранён экспорт отфильтрованной/отсортированной выборки на клиенте |
| Разделение Controller / Service / Repository | Добавлены REST Controller и клиентские HTTP-адаптеры |
| Развёртывание готового примера | Student Hub остаётся отдельным исходным примером; старые доказательства в docs/qa |
| Документация и тесты | Полный Word-гайд, REST-справка, проверки API и сквозного GUI |

Эта версия не утверждает буквальное соответствие пункту о прямом JDBC из JavaFX. Состав команды и дополнительные устные требования преподавателя согласует студент; авторизация/роли не добавлялись без отдельного требования.
